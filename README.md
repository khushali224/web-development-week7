# DG Interns Hub

A responsive internship discovery website built with React, React Router, Vite, and plain CSS.

## Features

- Home, Jobs, and Contact routes
- Search roles by title, skill, or company
- Filter opportunities by field and work arrangement
- Responsive internship cards with apply links
- Contact form with client-side confirmation

The job listings and email addresses are sample content. Replace them with verified DG Interns Hub opportunities and contact details before publishing.

## Run locally

```sh
npm install
npm run dev
```

## Verify and build

```sh
npm run lint
npm run build
npm run preview
```

## Deploy

Push the project to a GitHub repository, then import it into Netlify or Vercel. Use `npm run build` as the build command and `dist` as the publish/output directory. Configure the host to serve `index.html` for `/jobs` and `/contact` as well as `/` so direct route visits and refreshes work.
